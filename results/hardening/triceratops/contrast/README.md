# Contrast curves

`TOI218_zorro_562nm.txt`: separation (arcsec), comma, 5-sigma contrast (delta mag) from Gemini-South 'Zorro'
speckle imaging of TOI-218 at 562 nm on 2020-11-27 (PI S. Howell), taken from the public ExoFOP file
`TOI218I-ef20201127-562_sensitivity.dat` (fitted curve, separations >= 0.05 arcsec). Used by
`scripts/13_triceratops_run.py --contrast` with TRICERATOPS filter "Vis".
